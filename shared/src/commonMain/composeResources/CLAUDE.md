# composeResources/ — картинки

**Плоская структура — Compose Resources не поддерживает подпапки для
организации**, только qualifier-суффиксы (`-ru` и т.п.). Все 30+
иллюстраций грибов + логотип лежат прямо в `drawable/`.

## Раскладка по строке из БД

`Category.iconRef` (имя файла без расширения) резолвится через
`Res.allDrawableResources[iconRef]` (генерируемая `internal val
Map<String, DrawableResource>`) — **не** статический `Res.drawable.xxx`
accessor, тот нельзя выбрать по строке в рантайме.

## SVG не декодируется на Android

`painterResource` для SVG работает только через Skia (iOS/Desktop) — на
Android `IllegalStateException: doesn't support SVG format`. Любой
drawable, показываемый в приложении через `painterResource`, должен быть
растровым (PNG/WebP) заранее — SVG можно держать только как источник для
внешнего рендер-пайплайна (лончер-иконки), не класть его самого в
`composeResources`.

## Формат — WebP, не PNG

Все растровые ресурсы (грибы + логотип) — `.webp` (легче PNG при сравнимом
качестве, особенно на фото/градиентах). `iconRef`/`allDrawableResources`
не завязаны на расширение — переход не потребовал изменений в коде.

## Прозрачность

Часть присланных иллюстраций были экспортированы как RGB без настоящего
альфа-канала — вместо прозрачности в пиксели был растрирован слабый
шахматный узор (незаметен на вид, но давал шум при рендере на цветном фоне).
Если понадобится похожий разовый прогон снова: **flood fill от границ
изображения** для почти-белых пикселей (`r,g,b>232`, разброс каналов `<12`),
не глобальный порог — иначе задевает светлые части самих грибов
(шампиньон, дождевик), не связанные с фоном непрерывной областью.

## Лончер-иконки

Рендер SVG→PNG локально без интернет-инструментов —
`qlmanage -t` (macOS Quick Look thumbnail generator) как SVG-рендерер +
`sips` для ресайза/формата. Три варианта из одного SVG-исходника: плоский
full-bleed квадрат (iOS — Apple сама накладывает маску), круг (Android
legacy `ic_launcher_round`), прозрачный foreground без фона (Android
adaptive icon). **iOS-иконка обязана быть без альфа-канала** (Apple
отклоняет с прозрачностью) — канал убирается круглым провозом через JPEG
(`sips -s format jpeg` → обратно в PNG).
