# Исследование: 15 стран Западной, Северной Европы и Балкан

Входные материалы для браузерных сессий и формат, в котором результат
возвращается в репозиторий. План, который это обслуживает —
`.claude/plans/europe-15-countries.md`. Механика полностью повторяет прошлую
партию (`docs/research/post-soviet/`), отличия перечислены ниже.

## Какие страны

`AL`, `BA`, `BE`, `CH`, `CY`, `DK`, `GR`, `IE`, `IS`, `LU`, `ME`, `MK`, `NL`,
`NO`, `PT` — 15 подборок, 40 → 55.

## Чем эта партия отличается от прошлой

1. **Каталог не расширяется.** Условие владельца проекта: пул из 408 видов
   остаётся как есть, все 15 подборок собираются из него. Раздел `gaps` в
   промптах сохранён, но объявлен информационным (0–6 позиций) — он нужен,
   чтобы решение «не добавлять» было принято, зная цену, а не вслепую.
2. **Каталог этим странам подходит заметно лучше.** Проверено по данным перед
   постановкой задачи: в 408 видах уже есть средиземноморская специфика
   (`Amanita ponderosa`, `A. ovoidea`, `Lactarius sanguifluus`,
   `Hygrophorus latitabundus`, `Terfezia boudieri`, шесть трюфелей,
   `Boletus aereus`, `Pleurotus eryngii`) и атлантическо-нордическая
   (`Suillus grevillei`, `S. bovinus`, `S. variegatus`, `Craterellus
   tubaeformis`, `Cortinarius rubellus`, `Leccinum versipelle`). Риск «страну
   нечем собрать» здесь принципиально ниже, чем был у Средней Азии.
3. **Коридоры размера у трёх стран свои.** `IS` — 25–45 (ориентир 35) при 4–12
   опасных, `CY` — 35–50, `IE` — 35–55. Островная и безлесная микобиота честно
   даёт меньше пятидесяти, и промпт обязан разрешать короткий список, иначе
   сессия добьёт его видами, которых там не собирают.
4. **Языки подборок все попадают в интерфейс.** У прошлой партии этой проблемы
   не было видно, а она важна: названия грибов показываются **только для языка
   интерфейса** (`i18n/CategoryNames.kt` → `MushroomNames.namesFor(language)`),
   поэтому собранные названия на языке вне `AppLanguage` — мёртвые данные (как
   сейчас `names/ca.json`, `eu`, `gl`, `nah`, `tsz`, `maa`, `hch`, `tzo`, `mi`).
   Состав `languages` в промптах подобран так, что каждый код — это язык
   интерфейса после Фазы 4 плана. Люксембургский (`lb`) и ирландский (`ga`) по
   этой причине сознательно не собираются.
5. **Часть языков уже имеет корпус названий** — `en` (187), `fr` (110), `es`
   (97), `de` (85), `sv` (83), `sr` (76), `bg` (63), `hr` (62), `tr` (61),
   `it` (54). Для `CH`, `LU`, `BE`, `IE`, `CY`, `ME` промпт прямо требует
   **только дозаполнять пустые ключи** и не переписывать существующие: файл
   названий один на все подборки, и перезапись сломала бы имена в `DE`, `AT`,
   `FR`, `IT`, `GB`, `US`, `RS`. Расхождение пишется в `notes`.

## Как этим пользоваться

Одна браузерная сессия = одна страна. В сессию кладутся **два файла**:

1. `catalog_reference.tsv` — закрытый список 408 видов (общий для всех
   пятнадцати, 43 КБ);
2. `prompt_<CC>.md` — промпт конкретной страны.

Результат сессии — **один файл `research_<CC>.json`** плюс markdown-обоснование
в теле ответа. Готовые JSON положить в `docs/research/europe-15/results/` и
сказать об этом — дальше их разбирает Фаза 2 плана.

## `catalog_reference.tsv`

408 строк, TSV с заголовком. Собирается скриптом (в прошлый заход файл делался
разово и скрипта после себя не оставил, отчего `already_in` в нём застыл на 33
странах):

```bash
python3 tools/build_catalog_reference.py \
    docs/research/europe-15/catalog_reference.tsv \
    --names en,de,fr,es,it,sv,hr,sr,bg,tr
```

| колонка | что это |
|---|---|
| `key` | идентификатор вида в приложении — **единственное, что можно писать в `keys`** |
| `sci` | латинское имя (13 пар видов делят латынь — у них ключи с `__2`) |
| `en`…`tr` | уже имеющиеся названия на языках-соседях этой партии; пусто = названия нет |
| `breadth` | `narrow` — конкретный вид, `mid`/`broad` — народный концепт шире вида |
| `importance` | 3–5, оценка значимости из исходного дампа каталога |
| `dangerous` | ядовитый или требующий осторожности |
| `already_in` | коды стран (из 40), в чьих подборках вид уже есть — сильный географический сигнал |

Колонки названий подобраны под партию: датской сессии полезен шведский столбец,
македонской — болгарский и сербский, португальской — испанский, кипрской —
греческий и турецкий. **Промпты явно запрещают переводить из этих колонок** —
они нужны, чтобы понять, о каком концепте речь, и увидеть, что название уже
есть.

## Схема `research_<CC>.json`

Не изменилась против `docs/research/post-soviet/README.md`; `languages` и набор
языков внутри `names` у каждой страны свои и заданы её промптом:

| CC | `languages` | названия собираются на |
|---|---|---|
| AL | `sq` | `sq` |
| BA | `bs`, `hr`, `sr` | `bs` |
| BE | `nl`, `fr`, `de` | `nl`, `fr` |
| CH | `de`, `fr`, `it` | `de`, `fr`, `it` (дозаполнение) |
| CY | `el`, `tr` | `el`, `tr` |
| DK | `da` | `da` |
| GR | `el` | `el` |
| IE | `en` | `en` (дозаполнение) |
| IS | `is` | `is` |
| LU | `fr`, `de` | `fr`, `de` (дозаполнение) |
| ME | `sr` | `sr` (латиница, как в `names/sr.json`) |
| MK | `mk`, `sq` | `mk`, `sq` |
| NL | `nl` | `nl` |
| NO | `nb` | `nb` |
| PT | `pt` | `pt` |

Языки, которые пишут сразу несколько сессий: `el` (GR, CY), `sq` (AL, MK),
`nl` (NL, BE), `fr` (BE, CH, LU), `de` (CH, LU), `sr` (ME + существующая RS).
Их расхождения ловит сводка `tools/check_research.py`.

## Проверка результата

```bash
python3 tools/check_research.py --batch europe-15          # всё, что лежит в results/
python3 tools/check_research.py путь/research_DK.json
```

**Гонять на каждом файле по мере поступления, а не в конце** — пока сессия ещё
открыта, её можно переспросить.

Ошибки, предупреждения и сводка по нескольким файлам описаны в
`docs/research/post-soviet/README.md`; к ним в этой партии добавлены:

- **коридоры размера и доли опасных берутся из таблицы партии**, а не общие для
  всех (у `IS`, `CY`, `IE` они свои);
- **конфликт с уже существующим названием** в `names/<lang>.json` — отдельное
  предупреждение: сессия предложила имя для ключа, у которого имя уже есть.
  Это ровно тот случай, который в прошлой партии разбирался руками по русскому
  языку (31 новый ключ из 113 предложенных).
