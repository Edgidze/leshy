## Как этим пользоваться

Одна сессия = одна страна. В сессию кладётся **только** `prompt_<CC>.md` —
он самодостаточный: вся подборка страны с латынью, местным названием и
значимостью лежит прямо в нём. Приложенных файлов, в отличие от партий
`post-soviet` и `europe-15`, не требуется: состав подборки и названия уже
собраны, вопрос сессии узкий — только частотность.

Результат — файл `common_<CC>.json`, который кладётся на место нынешнего
(`docs/research/frequency/common_<CC>.json`, поверх версии с
`confidence: low`). Дальше:

```bash
python3 tools/apply_frequency_common.py   # проверка + заливка
python3 tools/build_catalog.py            # перегенерация countries.json
```

`apply_frequency_common.py` откажется принять файл, если ключ не принадлежит
подборке своей страны, если он повторяется или если частотных больше двадцати,
и предупредит, если у позиции из `common` нет строки в `evidence`.

Брифы собираются скриптом и правятся в нём, а не в готовых `.md`:

```bash
python3 tools/build_frequency_prompts.py
```

Текст про страну (контекст, ловушки, где искать) живёт в словаре `COUNTRY`
этого скрипта; таблица позиций собирается из `countries.json`, `catalog.json`
и `names/<lang>.json`, поэтому после перегенерации каталога брифы стоит
пересобрать — иначе сессия будет выбирать из устаревшего списка ключей.
