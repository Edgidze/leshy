# Исследование: 7 непокрытых стран постсоветского пространства

Входные материалы для браузерных сессий и формат, в котором результат
возвращается в репозиторий. План, который это обслуживает —
`.claude/plans/post-soviet-countries.md`.

## Что покрыто сейчас и чего нет

Из 15 постсоветских государств в приложении есть 8: `RU`, `UA`, `BY`, `MD`,
`EE`, `LV`, `LT`, `GE`. Нет семи: **`KZ`, `UZ`, `KG`, `TJ`, `TM`, `AZ`, `AM`**.

## Как этим пользоваться

Одна браузерная сессия = одна страна. В сессию кладутся **два файла**:

1. `catalog_reference.tsv` — закрытый список 408 видов каталога (общий для
   всех семи сессий, не меняется);
2. `prompt_<CC>.md` — промпт конкретной страны.

Результат сессии — **один файл `research_<CC>.json`** (схема ниже) плюс
markdown-обоснование в теле ответа. Готовые JSON положить в
`docs/research/post-soviet/results/` и сказать об этом — дальше их
разбирает Фаза 2 плана.

## `catalog_reference.tsv`

408 строк, TSV с заголовком. Генерируется из уже собранных данных приложения:

| колонка | что это |
|---|---|
| `key` | идентификатор вида в приложении — **единственное, что можно писать в `keys`** |
| `sci` | латинское имя (13 пар видов делят латынь — у них ключи с `__2`) |
| `ru`, `en`, `tr`, `ka` | уже имеющиеся народные названия; пусто = названия на этом языке ещё нет |
| `breadth` | `narrow` — конкретный вид, `mid`/`broad` — народный концепт шире вида |
| `importance` | 3–5, оценка значимости из исходного дампа каталога |
| `dangerous` | ядовитый или требующий осторожности |
| `already_in` | коды стран, в чьих подборках вид уже есть — сильный географический сигнал |

Файл собирается из `files/catalog/catalog.json`, `countries.json` и
`names/*.json`. Если каталог изменится до того, как исследование проведено, —
пересобрать, иначе сессии будут выбирать из устаревшего списка ключей.

## Схема `research_<CC>.json`

```jsonc
{
  "country": "KZ",
  "languages": ["kk", "ru"],        // языки подборки, титульный первым
  "keys": ["...", "..."],           // 40–55 ключей из catalog_reference.tsv,
                                    // по убыванию значимости для грибника страны
  "names": {
    "kk": { "<key>": "<народное название>" },
    "ru": { "<key>": "<народное название>" }
  },
  "coined": ["<key>"],              // названия, которых в источниках нет и
                                    // которые пришлось сконструировать
  "notes": { "<key>": "одна строка: почему вид в подборке + источник" },
  "gaps": [                         // важные для страны виды, которых нет в 408
    {
      "sci": "Morchella crassipes",
      "names": { "kk": "...", "ru": "..." },
      "why": "...",
      "nearest_key": "morchella_esculenta | null",
      "same_concept_as_nearest": false,
      "also_in": ["KG", "TJ"],
      "priority": "high | medium | low",
      "sources": ["..."]
    }
  ],
  "sources": ["..."]                // общий список источников исследования
}
```

## Что делается с результатом

- `keys` + `languages` → `docs/catalog/extra_country_presets.json` → генератор
  → `files/catalog/countries.json` (33 → 40 стран);
- `names` → `docs/catalog/extra_names/<lang>.json` → `files/catalog/names/<lang>.json`;
- `gaps` со `priority: high` → разбор в Фазе 3 плана: догенерация категорий и
  иллюстраций (256×256 webp с альфой), либо аргументированный отказ;
- `notes`/`sources` остаются здесь как обоснование состава подборок.

## Проверка результата

```bash
python3 tools/check_research.py                     # всё, что лежит в results/
python3 tools/check_research.py путь/research_KZ.json
```

Только стандартная библиотека — работает системным `python3`, без venv (в
отличие от `tools/build_catalog.py`). Код возврата 1, если есть ошибки;
предупреждения на код возврата не влияют.

**Гонять на каждом файле по мере поступления, а не в конце.** Проверки
внутрифайловые и стоят секунды, а если сессия выдала брак — она ещё открыта, и
её можно переспросить, вместо того чтобы поднимать заново.

Ошибки (файл возвращается в сессию): ключей нет в каталоге, дубликаты, взяты
оба ключа пары `X`/`X__2`, взяты два ключа одного вида под разными родовыми
именами, размер вне 40–55, доля опасных вне 8–19, `names` ссылается на ключи
вне `keys`, пустые названия, `coined`/`notes`/`nearest_key`/`also_in` ссылаются
не туда, битый `priority`.

Предупреждения (смотреть глазами, но не блокирует): состав `languages`
расходится с §7 плана, подборка короче обычных 50, нет названий на титульном
языке, позиции без `notes`, `gaps` без источников, `priority: high` при
`same_concept_as_nearest: true`, и — виды, входящие сейчас только в подборки
далёких стран (`AU`, `NZ`, `MX`, `JP`, `KR`, `US`, `CA`): вероятный признак
того, что ареал не проверили.

Про синонимы отдельно: промпт предупреждает только про пары с общей латынью
(`X` / `X__2`), но в каталоге есть и один вид под разными принятыми родами —
`Lepista nuda` = `Collybia nuda` = `Clitocybe nuda`, три отдельных ключа. Их
список в скрипте выверен вручную; эвристика по видовому эпитету для этого не
годится — `Morchella esculenta` и `Gyromitra esculenta` делят эпитет, но это
сморчок и строчок, и они вместе почти в каждой из 33 существующих подборок.

Когда файлов больше одного, печатается сводка по тому, что внутри одного файла
не видно:

- **конфликты названий между странами.** `names/<lang>.json` в приложении один,
  а `ru` просят все семь сессий; виды пересекаются, и варианты разойдутся
  («Вёшенка степная» против «Вешенка степная»). Выбирать один вариант надо,
  видя все рядом, иначе первый разложенный файл молча выигрывает;
- **слияние `gaps` по латыни** — сколько стран назвали один и тот же вид,
  расходятся ли они в `priority` и в том, отдельный ли это концепт. Это и есть
  вход в решение «окупается ли иллюстрация» (§4 плана).
