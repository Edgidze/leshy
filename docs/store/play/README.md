# `docs/store/play` — страница приложения в Google Play

Тексты и графика для листинга. Приложение нигде не опубликовано; это заготовка, которую
предстоит вставить в Play Console.

## Что здесь

| Файл | Что это |
|---|---|
| `listings.json` | **Источник правды.** `{ "<locale>": { "title", "short", "full" } }` |
| `listings.csv` | То же в CSV (RFC 4180, UTF-8) — генерируется, руками не править |
| `listing_<locale>.md` | По файлу на локаль, для ручной вставки в консоль |
| `convert_listings.py` | `listings.json` → CSV/TSV с произвольным набором колонок |
| `QA.md` | Длины полей, варианты названий, сверка каждого утверждения с кодом, открытые вопросы |
| `graphics/` | Иконка, баннер, скриншоты (`phone-<lang>/` готовые, `raw-<lang>/` сырые) |
| `demo-data/leshy-demo-<lang>.zip` | Демо-архив на локаль, на нём сняты скриншоты |
| `make_demo_archive.py`, `place_walk.py`, `place_others6.py` | Сборка демо-архива и расстановка прогулок по карте |
| `captions.json` | Подписи к скриншотам по локалям, в порядке `SCREENS` |
| `compose_shots.py`, `make_graphics.py` | Сборка скриншотов под требования магазина, иконка и баннер |

`compose_shots.py` обслуживает **оба** магазина: раскладка описана для холста Play (1080×1920) и
масштабируется на любой другой пресет — `--preset appstore` даёт комплект 6.9" iPhone
(1320×2868) для `docs/store/appstore/`. Шрифт подписей в репозитории не лежит, путь к нему
задаётся `--font` или `LESHY_CAPTION_FONT`.

## Как обновить тексты

Правится `listings.json`, дальше:

```bash
python3 convert_listings.py          # перегенерировать listings.csv (и проверить лимиты)
```

`convert_listings.py` откажется писать файл, если какое-то поле длиннее лимита Play
(30 / 80 / 4000 символов). Лимит проверяется **для каждой локали отдельно** — перевод, который
вырос при переводе, это самый обычный способ получить отказ на модерации.

Точная схема шаблона импорта переводов в Play Console публично не описана. Когда шаблон будет
скачан из консоли, менять надо только `COLUMNS` в `convert_listings.py`.

## Как пересобрать графику

```bash
python3 make_demo_archive.py en   # demo/ + leshy-demo-en.zip из экспорта владельца
python3 make_demo_archive.py ru   # то же с русскими названиями прогулок и мест
python3 compose_shots.py          # shots/*.png    -> play/phone-en/*.png
python3 compose_shots.py ru       # shots-ru/*.png -> play/phone-ru/*.png
python3 make_graphics.py          # иконка 512x512 и баннер 1024x500 на каждую локаль
```

Названия и описания прогулок и мест — это **контент архива**, а не интерфейс: приложение
переводит свои строки и названия грибов само, но прогулка «Ridge behind the bog» останется
английской при любом языке интерфейса. Поэтому на каждую локаль свой архив; тексты лежат в
`TEXTS` внутри `make_demo_archive.py` (около двадцати коротких строк на язык), подписи к
скриншотам — в `captions.json`.

Скрипты рассчитаны на рабочую директорию с исходниками (`walk/` — экспорт владельца,
`photos_src/` — фотографии мест, `shots/` — сырые снимки эмулятора, `osm_area.json` — выгрузка
Overpass по району). В репозиторий положены как справка о том, чем именно собраны артефакты.

## Съёмка комплекта на новом языке

Онбординг переигрывать не надо — данные приложения не стираются:

1. Архив прогулок → удалить шесть импортированных прогулок (открыть карточку → «Удалить» → «Да»;
   выделение долгим нажатием через `adb` не срабатывает, а поштучное удаление — шесть раз по три
   нажатия).
2. Настройки → «Язык интерфейса» → выбрать язык → подтвердить галочкой.
3. Экспорт/Импорт → «Импорт» → «Выбрать файл» → архив нужной локали → «Готово».
4. Предзагрузка: старый участок удалить и скачать заново с названием на новом языке —
   переименовать существующий нельзя. Экран всегда открывается на глобусе (`PreparationScreen`,
   `WORLD_VIEW_ZOOM`), до леса приходится доезжать двойными нажатиями и протяжками.
5. Снять семь статических экранов и прогнать живую прогулку для восьмого.

Две вещи, на которых это ломается, если о них не знать:

- **`adb shell input text` не умеет ничего, кроме ASCII** — на кириллице падает
  `NullPointerException`. Ставится ADBKeyboard (`ime enable`/`ime set com.android.adbkeyboard/.AdbIME`),
  текст шлётся броадкастом `am broadcast -a ADB_INPUT_TEXT --es msg '<текст>'`, после ввода
  обязательно `ime reset` — иначе в кадр попадёт его панель «ADB Keyboard (ON)».
- **Нажатие по «+» на плашке гриба срывается в долгое**, если прилетает, пока карта
  перерисовывается после сдвига позиции: `UP` доходит с задержкой, Compose видит долгое нажатие и
  открывает диалог «сколько нашли за раз», а следующие нажатия уходят в цифровую клавиатуру.
  Лечится ожиданием: сдвиг позиции → 12 с → нажатие → 6 с → следующий сдвиг.

## Требования Play, которые уже учтены

- скриншот телефона: сторона 320–3840 px и **не длиннее 2:1** — сырой кадр 1080×2400 этому не
  соответствует, поэтому в `phone-en/` лежат кадры 1080×1920;
- иконка: 512×512, 32-битный PNG с альфой;
- баннер: 1024×500, без альфы;
- в метаданных нет превосходных степеней, CAPS, эмодзи в названии, упоминаний цен, акций,
  других магазинов и конкурентов;
- дисклеймер о том, что приложение не определяет съедобность и не заменяет специалиста, стоит
  отдельным блоком в полном описании на обоих языках.
