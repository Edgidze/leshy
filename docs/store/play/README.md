# `docs/store/play` — страница приложения в Google Play

Тексты и графика для листинга. Приложение нигде не опубликовано; это заготовка, которую
предстоит вставить в Play Console.

## Что здесь

| Файл | Что это |
|---|---|
| `listings.json` | **Источник правды.** `{ "<locale>": { "title", "short", "full" } }` |
| `listings.csv` | То же в CSV (RFC 4180, UTF-8) — генерируется, руками не править |
| `listing_<locale>.md` | По файлу на локаль, для ручной вставки в консоль |
| `convert_listings.py` | `listings.json` → CSV/TSV с произвольным набором колонок |
| `QA.md` | Длины полей, варианты названий, сверка каждого утверждения с кодом, открытые вопросы |
| `graphics/` | Иконка, баннер, скриншоты (готовые и сырые) |
| `demo-data/leshy-demo.zip` | Демо-архив, на котором сняты скриншоты |
| `make_demo_archive.py`, `place_walk.py`, `place_others6.py` | Сборка демо-архива и расстановка прогулок по карте |
| `compose_shots.py`, `make_graphics.py` | Сборка скриншотов под требования Play, иконка и баннер |

## Как обновить тексты

Правится `listings.json`, дальше:

```bash
python3 convert_listings.py          # перегенерировать listings.csv (и проверить лимиты)
```

`convert_listings.py` откажется писать файл, если какое-то поле длиннее лимита Play
(30 / 80 / 4000 символов). Лимит проверяется **для каждой локали отдельно** — перевод, который
вырос при переводе, это самый обычный способ получить отказ на модерации.

Точная схема шаблона импорта переводов в Play Console публично не описана. Когда шаблон будет
скачан из консоли, менять надо только `COLUMNS` в `convert_listings.py`.

## Как пересобрать графику

```bash
python3 make_demo_archive.py    # demo/ + leshy-demo.zip из экспорта владельца (нужны walk/ и photos_src/)
python3 compose_shots.py        # shots/*.png -> play/phone/*.png
python3 make_graphics.py        # иконка 512x512 и баннер 1024x500
```

Скрипты рассчитаны на рабочую директорию с исходниками (`walk/` — экспорт владельца,
`photos_src/` — фотографии мест, `shots/` — сырые снимки эмулятора, `osm_area.json` — выгрузка
Overpass по району). В репозиторий положены как справка о том, чем именно собраны артефакты.

## Требования Play, которые уже учтены

- скриншот телефона: сторона 320–3840 px и **не длиннее 2:1** — сырой кадр 1080×2400 этому не
  соответствует, поэтому в `phone-en/` лежат кадры 1080×1920;
- иконка: 512×512, 32-битный PNG с альфой;
- баннер: 1024×500, без альфы;
- в метаданных нет превосходных степеней, CAPS, эмодзи в названии, упоминаний цен, акций,
  других магазинов и конкурентов;
- дисклеймер о том, что приложение не определяет съедобность и не заменяет специалиста, стоит
  отдельным блоком в полном описании на обоих языках.
